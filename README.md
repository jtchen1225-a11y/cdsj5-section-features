# 聖若瑟五校｜五大學部教育故事

公開展示網址：<https://jtchen1225-a11y.github.io/cdsj5-section-features/>

本頁把原有「特色課程清單」重組為家長及學生容易理解的三個問題：

1. 孩子會怎樣學？
2. 會得到甚麼成長？
3. 下一步可以走向哪裏？

## 內容定位

- 幼稚園部：自主探索、雙語啟蒙、品格教育
- 小學中文部：生活探究、文化扎根、分層支援
- 小學英文部：三語學術、跨學科創新、世界公民
- 中學中文部：AI賦能、產學合作、專業出路
- 中學英文部：英語研究、學術寫作、多元升學

## 正式發布前須確認

- 課程狀態：現正推行、試行或規劃中
- 2026/27新課程及合作資料
- Pearson國際考試的適用年級及安排
- 所有升學百分比的年份、分母、定義與來源
- 學生作品、照片及引語的公開授權
- 60/40比例是否只作內部資源規劃

目前版本為行政會議內容原型，不應把尚未確認的規劃視為正式招生承諾。
